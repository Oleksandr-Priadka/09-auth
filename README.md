📝 NoteHub (Next.js & Zustand)

NoteHub — це сучасний, високопродуктивний веб-додаток для створення, організації, пошуку та зручного перегляду нотаток. Проєкт побудований на базі Next.js 15 (App Router) із суворою типізацією TypeScript та гібридною архітектурою рендерингу (SSR / Client Components).

🚀 Основний функціонал

📋 Перегляд та фільтрація нотаток:

Фільтрація нотаток за категоріями (Todo, Work, Personal, Meeting, Shopping тощо) через динамічні роути (/notes/filter/[...slug]).

Пошук у реальному часі з дебаунсингом (Debounced Search).

Зручна пагінація сторінок за допомогою react-paginate.

🔍 Перехоплення маршрутів та модальні вікна (Intercepting Routes):

Перегляд деталей нотатки у модальному вікні без втрати контексту поточної сторінки завдяки паралельним та перехоплюваним роутам Next.js App Router (@modal/(.)notes/[id]).

✏️ Створення та керування нотатками:

Форма створення нової нотатки з валідацією полів у реальному часі через Formik та Yup.

Автозбереження чернетки (Zustand + Persist): Всі введені дані у форму створення автоматично зберігаються в localStorage за допомогою Zustand і відновлюються після оновлення сторінки.

⚡ Оптимізоване завантаження даних (SSR + React Query):

Початкове передзавантаження даних на сервері (prefetchQuery & HydrationBoundary) для максимальної SEO-оптимізації та швидкого першого рендеру.

Кешування та асинхронні запити на клієнті за допомогою TanStack React Query v5.

🎨 Сучасний та чуйний UI:

Стилізація на базі CSS Modules із чистими анімаціями та підлаштуванням під користувацькі екрани.

Сповіщення у реальному часі через react-hot-toast.

🛠️ Технологічний стек

Фреймворк: Next.js 15 (App Router, Server Components, Parallel/Intercepting Routes)

Мова: TypeScript

Управління станом (State Management): Zustand (із плагіном persist для збереження чернеток)

Робота з даними та HTTP: TanStack React Query v5, Axios

Форми та валідація: Formik, Yup

Стилізація: CSS Modules, clsx

UI компоненти та утиліти: react-paginate, react-hot-toast, @uiw/react-md-editor
